    About ZenFocus Pro

    ZenFocus Pro is a dual-dimensional (Desktop and Mobile viewports) professional focus environment engineered for deep work cycles, high-frequency task switching, and acoustic focus.

    Designed strictly to eliminate eye strain with zero font sizes below 19px, seamless light and dark mode contrasts, offline PWA capability, and fully contained Web Audio synthesis.

    How to Use

    1. Set Up Your Session: Select either 25-minute Focus mode or 5-minute Rest mode on the workspace dashboard.
    2. Activate Audio Masking: Click "Play Noise" to trigger smooth browser-generated brown noise to neutralize background chatter.
    3. Manage Deliverables: Open the right ⋮ menu to track daily actionable items and tweak font readability between 19px and 23px.
    4. 2D Screen Toggle: Use the 🖥️ View button on top to toggle between expansive desktop view and mobile phone simulator mode.
